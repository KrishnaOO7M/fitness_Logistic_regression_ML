# Fitness Prediction using Logistic Regression

## Overview
This project is a Machine Learning implementation of Logistic Regression for predicting fitness-related outcomes based on the given dataset.

The project covers the complete ML pipeline including:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Engineering
- Model Training
- Model Evaluation
- Prediction

The notebook is built using Python and Jupyter Notebook.


## Features
- Data preprocessing
- Missing value handling
- Correlation heatmap
- Visualization of important features
- Logistic Regression model training
- Accuracy evaluation
- Confusion Matrix
- Prediction analysis

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
